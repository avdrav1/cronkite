Install

All four apps with one command, for your user only, on Linux, macOS, or Windows (preview). No sudo or admin rights, no package manager. It runs each app's own installer in turn, keeps going if one fails, and ends with how each went.

Linux and macOS

curl -fsSL https://cronkite.cc/install.sh | sh

Paste it into a terminal; then start the apps from your app menu, or on a Mac from Launchpad or Applications. Only some of them: name them, as in curl -fsSL https://cronkite.cc/install.sh | sh -s -- slate frame.

Windows (preview)

irm https://cronkite.cc/install.ps1 | iex

Windows 10 and 11, 64-bit. Paste it into PowerShell; then start the apps from the Start menu. Only some of them: $env:CRONKITE_APPS = "slate frame"; irm https://cronkite.cc/install.ps1 | iex.

What an installer does

The suite's command runs the apps' installers one after another. Each one:

  1. Downloads the app's latest release for your system and checks it against its published sha256. If the checksum doesn't match, nothing is installed.
  2. On Linux, puts the app (brick, slate, frame, etch) in ~/.local/bin, and its menu entry and icon in ~/.local/share. On a Mac, puts it (Brick.app, …) in ~/Applications, with GTK and everything else it needs inside. On Windows, runs the app's Setup, which puts it in %LOCALAPPDATA%\Programs with GTK and everything else it needs inside, adds it to the Start menu, and lists it in Settings > Apps.
  3. On Linux, makes it the default app for its files (above), so double-clicking one opens it; other apps' defaults for other files are kept. On a Mac, its files list it under Open With, and your default apps stay as they are: to make it one, select a file in Finder, then File > Get Info > Open with > Change All. On Windows, its files list it under Open with, and your default apps stay as they are: to make it one, right-click a file, then Open with > Choose another app > the app > Always.

Requirements

macOS: a Mac with Apple Silicon (M1 or later) and macOS 14 Sonoma or later; nothing else to install. Intel Macs aren't supported.

Linux: an x86_64 system with GTK 4.14 or newer. GNOME desktops already have it. Tested on Arch, Ubuntu 24.04, and Fedora, and newer releases of each. If GTK 4 is missing, the installer tells you how to get it:

DistributionInstall GTK 4
Arch, Manjaro, EndeavourOSsudo pacman -S gtk4
Ubuntu 24.04+, Debian 13+sudo apt install libgtk-4-1
Fedorasudo dnf install gtk4
openSUSEsudo zypper install libgtk-4-1

Windows (preview): Windows 10 or 11, 64-bit; nothing else to install.

Update

The apps update themselves. When one starts, it checks for a newer release, downloads it in the background, and runs it from the next start; it installs only releases signed with Cronkite's key, and the first start of a new version says "Updated to Brick 0.6.0" (or whichever app and version) once. To turn that off, uncheck Update Automatically: in the ☰ main menu on Linux (Help in Etch), the app's menu on a Mac, Help on Windows. CRONKITE_NO_UPDATE=1 turns it off for one run. When it's off, the app makes no network request at all.

Apps installed before they updated themselves, or with updating turned off, update when you run the install command again, the suite's or an app's. It replaces the old versions and keeps your settings and recent files.

Uninstall

curl -fsSL https://cronkite.cc/install.sh | sh -s -- --uninstall
& ([scriptblock]::Create((irm https://cronkite.cc/install.ps1))) -Uninstall

Removes all four apps, on Linux with their menu entries and file defaults; on Windows, as Settings > Apps would. Your files, settings, and recent files are untouched. Only some of them: name them, as in sh -s -- --uninstall slate or -Uninstall -Apps slate.

One app on its own: its install command with | sh -s -- --uninstall in place of | sh, as in curl -fsSL https://slate.cronkite.cc/install.sh | sh -s -- --uninstall. On Windows, remove it in Settings > Apps > Installed apps, or run & ([scriptblock]::Create((irm https://slate.cronkite.cc/install.ps1))) -Uninstall (with the app's address).

Prefer a download?

Each app's download page has its latest release as a Linux .tar.gz, a Mac .dmg, and, in preview, a Windows Setup.exe, with its version, size, and sha256: Brick, Slate, Frame, Etch.

The apps aren't notarized by Apple yet, so the first time you open one from a DMG, macOS says it can't check it. On macOS 15 or later, open System Settings > Privacy & Security and click Open Anyway; on macOS 14, Control-click the app in Applications and choose Open. Or run xattr -dr com.apple.quarantine /Applications/Brick.app (with the app's name) once in Terminal. The install commands need none of this.

Nor are they signed for Windows yet, so when you open a downloaded Setup.exe, Windows may say “Windows protected your PC”: click More info, then Run anyway. Setup installs for your user and asks for no admin rights. The PowerShell commands need none of this.
