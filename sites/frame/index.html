Slides, without the ribbon.

Frame is a lightweight, native presentation app for Linux and macOS, and in preview for Windows. It opens PowerPoint decks, lets you edit them on the slide or as an outline, shows them full screen, and saves them back without touching what you didn't change.

Install

For your user, no sudo, on Linux or a Mac.

curl -fsSL https://this-site/install.sh | sh

On Linux it installs the app, its menu entry, and .pptx files opening with it; start it from your app menu or with frame. It needs GTK 4, which GNOME desktops have; otherwise the installer says how to get it.

On a Mac with Apple Silicon and macOS 14 or later, it puts Frame in your Applications folder, with everything it needs inside. PowerPoint presentations list Frame under Open With; to open them with Frame by default, select one in Finder, then File > Get Info > Open with > Change All.

To remove it:

curl -fsSL https://this-site/install.sh | sh -s -- --uninstall

On Windows 10 and 11, 64-bit (a preview): for your user, no admin rights. Paste this into PowerShell.

irm https://this-site/install.ps1 | iex

It puts Frame in your user's Programs folder, with everything it needs inside, and in the Start menu. PowerPoint presentations list Frame under Open with, and Windows keeps your default apps; to open them with Frame by default, right-click one, then Open with > Choose another app > Frame > Always.

To remove it, use Settings > Apps > Installed apps, or:

& ([scriptblock]::Create((irm https://this-site/install.ps1))) -Uninstall

Frame updates itself: when it starts, it checks for a newer release, downloads it in the background, and runs it from the next start. It installs only releases signed with Cronkite's key. To turn that off, uncheck Update Automatically (the ☰ main menu on Linux, the Frame menu on a Mac, Help on Windows), or start it with CRONKITE_NO_UPDATE=1 set. A copy installed before Frame updated itself needs the install command run once more.

From the DMG: open it and drag Frame to Applications. Frame isn't notarized by Apple yet, so the first time you open it macOS says it can't check it. On macOS 15 or later, open System Settings > Privacy & Security and click Open Anyway beside Frame's name; on macOS 14, Control-click Frame in Applications and choose Open. Or run this once in Terminal:

xattr -dr com.apple.quarantine /Applications/Frame.app

From Setup.exe: Frame isn't signed yet, so when you open it Windows may say “Windows protected your PC”. Click More info, then Run anyway. Setup installs for your user and asks for no admin rights.

The install commands need none of this: what curl and PowerShell download isn't flagged. Check a download against its sha256 with shasum -a 256 on a Mac, sha256sum on Linux, or Get-FileHash in PowerShell.
