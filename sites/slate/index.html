Write on one endless page.

Slate is a lightweight, native word processor for Linux and macOS, and in preview for Windows. It opens Word documents, Markdown, and plain text, lets you edit them as they look, and saves them back without touching what you didn't change.

Install

For your user, no sudo, on Linux or a Mac.

curl -fsSL https://this-site/install.sh | sh

On Linux it installs the app, its menu entry, and Word documents and Markdown files opening with it; start it from your app menu or with slate. It needs GTK 4, which GNOME desktops have; otherwise the installer says how to get it.

On a Mac with Apple Silicon and macOS 14 or later, it puts Slate in your Applications folder, with everything it needs inside. Word documents, Markdown, and plain text list Slate under Open With; to open them with Slate by default, select one in Finder, then File > Get Info > Open with > Change All.

To remove it:

curl -fsSL https://this-site/install.sh | sh -s -- --uninstall

On Windows 10 and 11, 64-bit (a preview): for your user, no admin rights. Paste this into PowerShell.

irm https://this-site/install.ps1 | iex

It puts Slate in your user's Programs folder, with everything it needs inside, and in the Start menu. Word documents, Markdown, and plain text list Slate under Open with, and Windows keeps your default apps; to open them with Slate by default, right-click one, then Open with > Choose another app > Slate > Always.

To remove it, use Settings > Apps > Installed apps, or:

& ([scriptblock]::Create((irm https://this-site/install.ps1))) -Uninstall

Slate updates itself: when it starts, it checks for a newer release, downloads it in the background, and runs it from the next start. It installs only releases signed with Cronkite's key. To turn that off, uncheck Update Automatically (the ☰ main menu on Linux, the Slate menu on a Mac, Help on Windows), or start it with CRONKITE_NO_UPDATE=1 set. A copy installed before Slate updated itself needs the install command run once more.

From the DMG: open it and drag Slate to Applications. Slate isn't notarized by Apple yet, so the first time you open it macOS says it can't check it. On macOS 15 or later, open System Settings > Privacy & Security and click Open Anyway beside Slate's name; on macOS 14, Control-click Slate in Applications and choose Open. Or run this once in Terminal:

xattr -dr com.apple.quarantine /Applications/Slate.app

From Setup.exe: Slate isn't signed yet, so when you open it Windows may say “Windows protected your PC”. Click More info, then Run anyway. Setup installs for your user and asks for no admin rights.

The install commands need none of this: what curl and PowerShell download isn't flagged. Check a download against its sha256 with shasum -a 256 on a Mac, sha256sum on Linux, or Get-FileHash in PowerShell.
