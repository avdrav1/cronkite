I just need to edit this image.

Etch is a fast, simple, native image editor for Linux and macOS, and in preview for Windows, closer to Paint than to Photoshop. Open a PNG, JPEG, or BMP, draw with the pencil, brush, fill, lines, rectangles, ellipses, and text, select and move pixels, copy and paste with other apps, crop, resize, rotate, and flip, then save. Every step undoes.

Install

For your user, no sudo, on Linux or a Mac.

curl -fsSL https://this-site/install.sh | sh

On Linux it installs the app and its menu entry; start it from your app menu or with etch. It makes Etch the default app for PNG, JPEG, and BMP images, so double-clicking one opens it in Etch; other file types keep their apps, and removing Etch drops its defaults. It needs GTK 4, which GNOME desktops have; otherwise the installer says how to get it.

On a Mac with Apple Silicon and macOS 14 or later, it puts Etch in your Applications folder, with everything it needs inside. PNG, JPEG, and BMP images list Etch under Open With; to open them with Etch by default, select one in Finder, then File > Get Info > Open with > Change All.

To remove it:

curl -fsSL https://this-site/install.sh | sh -s -- --uninstall

On Windows 10 and 11, 64-bit (a preview): for your user, no admin rights. Paste this into PowerShell.

irm https://this-site/install.ps1 | iex

It puts Etch in your user's Programs folder, with everything it needs inside, and in the Start menu. PNG, JPEG, and BMP images list Etch under Open with, and Windows keeps your default apps; to open them with Etch by default, right-click one, then Open with > Choose another app > Etch > Always.

To remove it, use Settings > Apps > Installed apps, or:

& ([scriptblock]::Create((irm https://this-site/install.ps1))) -Uninstall

Etch updates itself: when it starts, it checks for a newer release, downloads it in the background, and runs it from the next start. It installs only releases signed with Cronkite's key. To turn that off, uncheck Update Automatically (Help on Linux, the Etch menu on a Mac, Help on Windows), or start it with CRONKITE_NO_UPDATE=1 set. A copy installed before Etch updated itself needs the install command run once more.
